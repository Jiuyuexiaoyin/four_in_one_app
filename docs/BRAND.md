# Get Ready 品牌规范

本文档定义 Get Ready 2.6.0 在应用界面、Android 资源和仓库文档中的统一品牌用法。精确几何尺寸与生成结果以 `reports/p11_get_ready_geometry_spec.md` 和品牌生成清单为准。

## 核心身份

- **正式名称**：Get Ready
- **正式标语**：随时准备，迎接每一次机会。
- **产品版本**：2.6.0
- **品牌含义**：开放、准备、专注、行动、进步、机会

产品名在所有用户可见位置都必须保留首字母大写和单词间空格。不得改为全小写、全大写或无空格拼接形式。内部文件名、Dart 标识符、Android 资源名、包名、路由键和通知渠道 ID 可按技术约束继续使用稳定格式。

## 标志概念

Get Ready 标志由三个几何元素组成：

1. **开放圆弧**：一条端点圆润、不对称的自定义 Bézier 圆弧，开口朝右；上端点接近右上方，下端点明显收向底部中心，不能镜像成对称 C。开放形态代表机会与可进入的行动空间。
2. **状态栏**：位于圆弧开口下半部并与圆弧外接范围重叠的一条绿色水平圆角条，代表已准备、可行动的状态。
3. **准备圆点**：位于状态栏下方的绿色圆点，用来平衡构图并形成明确状态信号。

三个元素共同形成抽象的 G / readiness / status 符号。它不是字体中的字母 C，也不是装饰插画。

状态栏必须保持紧凑，圆点必须具有清晰视觉重量。生产母稿使用状态栏 `225 × 75` 与圆点直径 `150`：宽度/圆点直径为 `1.50`，高度/圆点直径为 `0.50`，边缘垂直间距为圆点直径的 `0.313`。圆点中心相对状态栏中心向右 `23.5` units（约 `0.045` 个圆弧宽度），与批准参考的光学错位一致。不得恢复为长条加小圆点、共享中心的高位信号组或对称 C 圆弧。

## 品牌主稿

生产主稿位于 `assets/branding/`：

- `get_ready_mark.svg`：主 Launcher 组合，Ink black tile、近白圆弧、绿色状态栏和圆点。
- `get_ready_mark_dark.svg`：透明深色表面版本，白色或近白圆弧、绿色状态栏和圆点。
- `get_ready_mark_light.svg`：透明浅色表面版本，黑色圆弧、绿色状态栏和圆点。
- `get_ready_mark_monochrome.svg`：单色/系统着色版本。
- `get_ready_wordmark_horizontal.svg`：横向标志与正式名称组合。
- `get_ready_logo_vertical.svg`：纵向组合。
- `get_ready_splash_logo.svg`：Splash 使用的组合主稿。

所有 PNG、Android Launcher、Adaptive Icon、themed icon、notification icon、Splash 和证明图都应由这些矢量主稿或同一份受控几何数据生成。不得从批准参考板截图或裁切生产资产。

## Wordmark

Wordmark 的可见文字必须精确写作 **Get Ready**：

- `Get` 在浅色背景上使用 Ink black，在深色背景上使用白色或近白。
- `Ready` 使用 Brand green。
- 两个单词之间保留清晰可见的空格。
- 使用现代、清晰的 sans-serif 系统字体或开放字体；仓库不嵌入商业字体文件。
- 不拉伸、压缩、倾斜、描边或改变字母大小写关系。

## 颜色

| Token | Hex | RGB | 推荐用途 |

| Ink black | `#111111` | `17, 17, 17` | 主文字、Launcher/Splash 主背景 |
| Brand green | `#16A34A` | `22, 163, 74` | 状态栏、圆点、Ready、行动强调 |
| Deep gray | `#6B7280` | `107, 114, 128` | 次级文字、注释 |
| Light gray | `#E5E7EB` | `229, 231, 235` | 浅色分隔线、边界 |
| Background gray | `#F6F7F8` | `246, 247, 248` | 浅色品牌背景 |

### 浅色背景

- 圆弧：`#111111`
- 状态栏：`#16A34A`
- 圆点：`#16A34A`
- `Get`：`#111111`
- `Ready`：`#16A34A`

### 深色背景

- 圆弧：白色或近白
- 状态栏：`#16A34A`
- 圆点：`#16A34A`
- `Get`：白色或近白
- `Ready`：`#16A34A`

Brand green 不应被渐变、光晕或纹理替换。应用主题允许用户选择其他强调色，但产品标志仍使用正式品牌绿。

## 构图、安全区与小尺寸

- 始终使用矢量主稿定义的比例、开口方向、内部间距和圆角。
- 在标志四周保留主稿规定的安全区；不要让文字、裁切边界或设备遮罩贴近圆弧端点。
- Launcher 前景不包含圆角方形容器；深色背景必须作为 Adaptive Icon 的独立 background layer。
- 标志缩小到 16–24 px 时，圆弧、状态栏和圆点仍需保持可分辨，不能融合成实心块。
- 小尺寸版本可以做受控的光学校正，但不能改变三元素关系。
- Wordmark 不放入 Launcher 或 notification icon。

精确 canvas、不对称 Bézier 路径、归一化端点、圆弧外接框、状态栏和圆点尺寸、最小尺寸见 P11 几何规范。

## Android 使用规则

### Launcher 与 Adaptive Icon

- 主背景使用 `#111111`。
- 标志居中，并为圆形、squircle、圆角方形及厂商遮罩保留充足安全区。
- Adaptive foreground 仅包含标志，不烘焙背景或圆角容器。
- Android 13+ themed icon 使用有效的 monochrome 资源。

### Notification icon

- 透明背景。
- 单色实心轮廓，由 Android 在运行时着色。
- 不使用绿色、渐变、阴影、方形底或 Wordmark。
- 必须在状态栏实际尺寸下清晰可辨。

### Splash

- 主背景使用 `#111111`。
- Android 12+ 原生 Splash 遵循平台图标限制，使用居中的标志。
- 旧版 Splash 可使用适合平台约束的标志/Wordmark 组合。
- 不添加进度条、人工等待或会造成白闪的额外过渡。
- 标语仅在空间和可读性允许的 Flutter 首帧/品牌预览中使用。

## 文档与截图

- README hero 使用 `assets/branding/get_ready_wordmark_horizontal.svg`。
- 仓库文档中的产品标题统一为 Get Ready。
- 品牌证明图可以展示浅色、深色、遮罩、小尺寸、通知和 Splash 状态。
- 新旧对比图仅用于迁移证明，不能作为生产图标、Splash 或 README hero。
- `.ai_reference/` 中的批准板仅作为设计依据，不得提交或直接链接为生产素材。

## 禁止用法

- 继续使用旧三阶标志作为用户可见品牌。
- 关闭圆弧或把开口改向其他方向。
- 合并状态栏与圆点，或把圆点移动到状态栏同一水平线。
- 改变圆弧、状态栏和圆点的相对比例或间距。
- 添加渐变、发光、投影、纹理、装饰插画或照片背景。
- 从截图、品牌板或证明图裁切生产资产。
- 在 Launcher foreground 内绘制圆角方形背景。
- 在 notification icon 中使用颜色或容器。
- 改写正式名称的大小写或空格。

## 可访问性与质量检查

- 提供有意义的替代文字，例如“Get Ready 标志”，不要把文件名作为 alt text。
- 在浅色和深色表面检查圆弧与背景对比度。
- 检查 16、24、32、64、128 和 512 px 下的边缘、间隙和透明像素。
- 检查 PNG 为 sRGB、Alpha 正确、边缘未裁切且无透明彩边。
- Android 最终外观必须在真实设备上检查 Launcher 遮罩、themed icon、Splash 和状态栏图标。

## 版本管理

品牌主稿、生成工具和生成资产应在同一发布批次中更新。修改几何或颜色后，应重新生成所有衍生资产和证明图，并在 release report 中记录验证结果。不要手工只替换某一个密度或平台资源。
