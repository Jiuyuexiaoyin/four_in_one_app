# P7 Visual Brief

P7 UI work must be structure-first and reference-driven. The goal is a modern,
minimal, premium, calm app with a recognizable visual rhythm and strong
personalization through Theme Studio.

## We Want

- modern
- minimal
- premium
- calm
- rhythm-based
- fewer cards
- less text
- more visual objects
- wave/path/dots/graphical rhythm
- The Outsiders-style rhythm and data visuals
- Equinox+ style full-screen stage / editorial headline
- Theme Studio custom colors must remain visible

## Reject

- color-only redesign
- token-only redesign
- giant rounded dashboard card
- dense database-like records
- table-like month grid
- hiding functional entry points
- losing Theme Studio
- generic dark dashboard
- old stacked-card structure

## Theme Studio Requirement

Custom background, card, and accent colors must affect real page surfaces,
hero/stage atmosphere, selected states, CTA treatments, rhythm marks, chart
accents, and highlighted borders. A fixed hardcoded palette must not swallow
user customization.

## UI Implementation Standard

Every UI implementation task must cite:

- current app screenshots from `docs/references/current_app_ui`
- desired/taste references from `docs/references/ui_taste_board`
- benchmark or functional references from `docs/references`

If references are missing, uncited, or unindexed, the task should stop at
planning/audit instead of implementation.
